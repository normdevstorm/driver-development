# Linux Kernel Driver Development Project - CentOS 9 64-bit

This is a Linux kernel driver development project focusing on:
- Kernel module development for CentOS 9 64-bit (RHEL 9 compatible)
- Socket-based chat application with encryption
- DES encryption and SHA1 hashing in kernel space
- USB keyboard driver implementation

## Development Guidelines
- All kernel code should be compatible with Linux kernel 5.14+ (CentOS 9 64-bit)
- Use modern kernel APIs for memory management, synchronization, and device handling
- Follow Linux kernel coding style and conventions
- Implement proper error handling and cleanup mechanisms
- Use modern kernel crypto APIs (skcipher for DES, shash for SHA1)
- Ensure thread-safe operations in kernel space
- Support 64-bit architecture and addressing

## Migration Notes from CentOS 32-bit to CentOS 9 64-bit
- Updated crypto API usage (removed USE_SIMPLE_CIPHER, using skcipher API)
- Modern kernel compatibility (5.14+)
- 64-bit memory addressing and pointer handling
- Updated build system (dnf instead of yum)
- Modern compiler flags and optimizations
- Updated driver version numbers and descriptions

## Key Changes Made
1. **Crypto Driver**: Updated to use modern skcipher API instead of deprecated cipher API
2. **USB Keyboard Driver**: Updated driver name and version for CentOS 9
3. **Build System**: Updated Makefiles with 64-bit flags and modern kernel compatibility
4. **Documentation**: Updated system requirements and installation instructions
5. **Scripts**: Updated build scripts for DNF package manager and kernel version checks
